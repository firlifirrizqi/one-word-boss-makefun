# One Word for the Boss

Make.fun entry for **One Word for the Boss** — send exactly one word that
describes your boss: no phrase, no caption, no explanation.

## The word

**Ideathief**

The boss who hears your idea on Monday, forgets you said it by Wednesday,
and presents it in Friday's meeting as if it were always his own. Every
employee has met him, in every office, kitchen and warehouse — and the word
lands on its own, no caption needed.

## Run

```bash
python3 main.py
```

This writes the single word to `/output/entry.txt` (validated first: one
word, 1–30 characters, letters only), then reads it back to confirm the file
is byte-identical to the chosen word.
